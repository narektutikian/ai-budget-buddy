# Architecture

This directory will hold the architecture documentation for AI Budget Buddy. Nothing here is decided until it is written down, and significant choices are recorded as ADRs in [../adr/README.md](../adr/README.md).

## Index

| Document | Description | Status |
| --- | --- | --- |
| System context | Actors, external systems, and system boundary | Planned |
| Data model | Core entities (transactions, categories, debts, goals) and their relationships | Planned |
| Ingestion design | How transactions enter the system (Gmail or file import; decision pending) | Planned |
| Threat model | Assets, trust boundaries, threats, and mitigations for financial data and PII | Planned |

Diagrams will be added as the corresponding decisions are made.
